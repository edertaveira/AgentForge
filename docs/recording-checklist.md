# Checklist de gravação

## Antes de abrir o gravador

- [ ] Fechar e-mails, mensagens e abas pessoais.
- [ ] Ativar modo não perturbe e ocultar notificações.
- [ ] Confirmar que `.env` e credenciais não estão abertos.
- [ ] Usar uma tarefa fictícia sem dados de cliente.
- [ ] Confirmar Node.js 22 ou superior com `node --version`.
- [ ] Confirmar o checkpoint indicado no roteiro.
- [ ] Confirmar repositório limpo com `git status --short`.
- [ ] Executar os testes da aula antes de gravar.
- [ ] Limpar a saída do terminal e aumentar a fonte.

## Durante a aula

- [ ] Dizer o objetivo em uma frase.
- [ ] Mostrar a entrada antes da saída.
- [ ] Diferenciar fato, hipótese e dúvida bloqueante.
- [ ] Explicar cada autorização concedida.
- [ ] Mostrar somente o trecho relevante do diff.
- [ ] Dizer quais testes realmente foram executados.
- [ ] Mostrar a evidência produzida pelo mesmo run.
- [ ] Encerrar com a decisão humana.

## Antes de publicar a aula

- [ ] Rever o vídeo procurando tokens, e-mail, URL privada e histórico do terminal.
- [ ] Confirmar que nenhuma afirmação excede a evidência mostrada.
- [ ] Cortar esperas, instalações e digitação sem valor pedagógico.
- [ ] Inserir recurso para download e referência ao checkpoint.
- [ ] Anotar versão do projeto e data da gravação.

## Frase de segurança para aulas práticas

> O agente prepara e valida a mudança dentro dos limites concedidos. A decisão de publicar ou
> integrar a entrega continua sendo humana.
